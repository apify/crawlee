[Lightpanda](https://lightpanda.io/) is a headless browser written from scratch in Zig. It runs JavaScript with V8 but does not render pages, so it uses far less memory and CPU than headless Chrome. It exposes a Chrome DevTools Protocol (CDP) server, so <ApiLink to="playwright-crawler/class/PlaywrightCrawler">`PlaywrightCrawler`</ApiLink> and <ApiLink to="puppeteer-crawler/class/PuppeteerCrawler">`PuppeteerCrawler`</ApiLink> can connect to it through the [remote browser](./remote-browser) support. No separate crawler class is needed.

Lightpanda does not implement every web API that Chrome does. Test it on your target sites before you switch.

## Start Lightpanda

Install it with Homebrew, download a binary from the [releases page](https://github.com/lightpanda-io/browser/releases) (Linux and macOS), or run the Docker image:

```bash
brew install lightpanda-io/browser/lightpanda
lightpanda serve --host 127.0.0.1 --port 9222

# or
docker run -d --name lightpanda -p 127.0.0.1:9222:9222 lightpanda/browser:nightly
```

Build the pool with <ApiLink to="playwright-crawler/function/remotePlaywrightBrowserPool">`remotePlaywrightBrowserPool()`</ApiLink> and point it at the server:

<CodeBlock language="ts" title="src/main.ts">{LightpandaConnectSource}</CodeBlock>

Lightpanda allows only one browser context per CDP connection. Set `maxOpenPagesPerBrowser: 1` so that the pool opens a new connection for each concurrent page. With the shorter `remoteBrowser: { endpoint }` option, the pool keeps the default of several pages per browser. The second page on a connection then fails with `Cannot have more than one browser context at a time` in Playwright, or `TargetAlreadyLoaded` in Puppeteer.

Keep `maxOpenBrowsers` at or below the server's `--cdp-max-connections` value, which defaults to 16.

For Puppeteer, use <ApiLink to="puppeteer-crawler/function/remotePuppeteerBrowserPool">`remotePuppeteerBrowserPool()`</ApiLink> with the same options.

## Proxies

Lightpanda sets its proxy for the whole process with the `--http-proxy` flag. A single shared server therefore cannot follow Crawlee's per-browser proxy rotation. If you use a <ApiLink to="core/class/ProxyConfiguration">`ProxyConfiguration`</ApiLink>, start one Lightpanda process per browser with a <ApiLink to="browser-pool/class/RemoteBrowserProvider">`RemoteBrowserProvider`</ApiLink>. ## Useful server flags

- `--obey-robots` fetches and follows the target site's `robots.txt`.
- `--load-resources iframe|worker|stylesheet|image` turns on loading of iframes, web workers, external stylesheets or images. Since Lightpanda 0.4.0, none of them load by default. Pass the flag once for each resource type.
- `--cdp-max-connections` sets the maximum number of simultaneous CDP connections.

Run `lightpanda help serve` for the full list.
